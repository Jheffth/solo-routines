# v1.7.0 - 2026-07-25

## Refatoracao Arquitetural: Rotinas x Missoes (Extrato)

Esta versao resolve uma distincao conceitual fundamental que causava bugs
silenciosos no dashboard e no extrato de atividades.

### O Problema Resolvido

Antes: ROTINA e MISSAO eram tratadas como a mesma entidade. O dashboard
pedia /rotinas/hoje e recebia templates com status_hoje grudado - por isso
o extrato nao conseguia mostrar nenhum dia alem de hoje.

Agora a distincao e explicita:
- ROTINA = a REGRA ("carregar Dolphin toda terca") -> guia Rotinas
- MISSAO = a OCORRENCIA ("carregar Dolphin em 14/07") -> Dashboard/Extrato

### Novos Arquivos

- webapp/backend/routers/extrato.py
  Endpoint GET /api/extrato/ - livro-caixa unificado do hunter.
  Paramentros: inicio, fim, origem, status, tipo, limite.
  uid unico por missao (r123 para rotinas, g45 para gerais).

- webapp/backend/motors/celebracao.py
  Resolve loop infinito de celebracoes. Nova convencao sr_eventos:
  o backend DECLARA o que deve virar festa. Se sr_eventos nao existe,
  nao ha celebracao.

- webapp/backend/motors/fechamento.py
  Motor de fechamento do dia (idempotente). Materializa instancias de
  dias que nao foram abertos. Fecha PENDENTE/ATIVA de dias passados ->
  FRACASSADA com penalidade. Resolve o bug onde dias vencidos ficavam
  PENDENTE para sempre.

- webapp/CONTRATO_EXTRATO.md
  Contrato entre backend e frontend para o sistema de extrato.
