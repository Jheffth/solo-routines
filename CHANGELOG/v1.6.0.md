# v1.6.0 — 2026-07-24

## Sistema de Versionamento
- Criado endpoint `GET /api/versao` que expõe versão semântica, git SHA, ambiente e timestamp
- Footer do app exibe versão em tempo real comparável entre local e Render
- Arquivo `VERSION` na raiz controla a versão semântica do projeto
- Pasta `CHANGELOG/` criada para notas de atualização por versão

## Correções de Bugs (Audit Fable Method)
- Segurança: endpoint de webhook Telegram agora exige autenticação de Arquiteto
- Corrigida rota `PATCH→POST` em `tarefas/concluir` (tarefas não concluíam)
- Corrigido payload `PUT /configuracoes/batch` (configurações não salvavam)
- Adicionada rota `GET /api/hunters` para o console do Arquiteto
- Adicionada rota `POST /auth/logout` (eliminado 404 no logout)
- Corrigida rota `/admin/configs` → `/configuracoes/` no frontend
- Migradas chamadas `fetch()` diretas para `API.class` no arquiteto-console

## CSS Design System
- Declaradas variáveis CSS fantasma: `--purple-light`, `--border-glow`, `--transition`, `--font-mono`, `--font-digits`
- Adicionadas variáveis de cor por rank: `--rank-e` até `--rank-national`

## UX Premium
- Loading states nos botões de ação da Loja
- Empty states premium no Perfil (conquistas) e Materiais (histórico)
- Arquivos `.bak` residuais removidos
